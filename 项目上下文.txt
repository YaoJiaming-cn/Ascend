ResNet-50 训练 — 最终结果（from scratch, 15 epochs）：
  - 训练准确率: 16.8% → 95.6%（清晰的爬坡曲线）
  - 验证准确率: 23.8% → 84.3%（最佳）
  - 总训练时间: 43.3 分钟（2599s）
  - NPU vs CPU 加速: 127.6x（CPU batch 53.5s vs NPU batch 0.4s）
  - 平均 epoch 耗时: ~173s/epoch
  - 图表: training_curves.png（loss + acc + epoch time 三图）

关键踩坑记录（对写报告有参考价值）：
  - AtomGit 免费环境 Bus error → 换华为云 ModelArts 付费实例解决
  - CIFAR-10 从 cs.toronto.edu 下载极慢 → VPN加拿大节点解决 → 上传云端
  - CANN SyntaxWarning 刷屏 → sys.warnoptions.append('ignore') 解决
  - pretrained=True 导致 Epoch1 即 98% 无学习曲线 → 改 from scratch + lr=0.05
  - num_workers=2 在免费容器报 shared memory 不足 → num_workers=4 在付费实例正常
  - DataLoader workers 需设置 torch.multiprocessing.set_sharing_strategy('file_system')

【架构核心知识】
NVIDIA GPU  ←→  达芬奇架构 (Ascend NPU)
CUDA+cuDNN  ←→  CANN (异构计算架构)
torch.cuda   ←→  torch_npu (PyTorch 适配 NPU 的插件)
PyTorch      ←→  MindSpore (华为自研框架，原生适配昇腾)

迁移核心: import torch_npu; device='npu:0'; .to('npu:0')
NPU 异步执行，计时需 torch_npu.npu.synchronize()
PyTorch 显示 cpu 版本是正常的，NPU 能力全由 torch_npu 提供
